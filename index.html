How to use the image

As an <img>

Keep it crisp and accessible with an alt attribute. This is what the hero uses. 

<img src="./assets/hero.png" alt="..." />

As a CSS background

Great for banners. You can apply it to any block element. 

.banner {
  background: url("./assets/hero.png") center / cover no-repeat;
}
