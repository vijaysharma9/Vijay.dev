# Web Development Image Usage

This folder contains a simple static page that uses your provided image as a web asset.

## Files

- `index.html`: Demo page that loads the image.
- `styles.css`: Styling for the demo page.
- `assets/hero.png`: The image you provided (copied into the project).
- `index (4).html`: Your existing page (left untouched).

## Run locally

Open `index.html` in a browser.

If you prefer using a local server (recommended for web dev), run:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173` and click `index.html`.
